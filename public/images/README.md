# Product photos

The photos are not included in this repo. Add your own here with these names:

| File | Shows |
|---|---|
| `pegasus-43-side.avif` | Side view (first photo) |
| `pegasus-43-sole.avif` | Outsole |
| `pegasus-43-pair.avif` | Pair from the front |
| `pegasus-43-detail.avif` | Close-up of the heel and midsole |

Square images about 750 x 750 px or larger work best. JPG, PNG and WebP also work: change the file names in the `slides` list in `src/app/page.tsx` to match.

Until a photo is added, the carousel shows a placeholder in its place.
